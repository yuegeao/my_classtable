# 极简课表 · 产品设计文档 + 可运行网页端代码

一款**拒绝功能臃肿、追求极速启动**的极简课表应用。本目录包含完整产品设计（页面结构、交互逻辑、数据模型、性能策略）与一套**开箱即用的网页端实现**（`index.html` + `style.css` + `app.js`，纯静态、零构建、双击即用）。

---

## 1. 产品概述

| 维度 | 说明 |
|---|---|
| 产品形态 | 移动端优先的 Web App（也可作为桌面浏览器工具） |
| 核心定位 | 打开即见课表；手动添加课程；倒计时直观 |
| 技术栈 | 原生 HTML / CSS / JS，无框架、无构建、无开屏动画 |
| 数据存储 | 浏览器 localStorage（本地持久化，支持导出备份） |
| 首次加载 | 单文件体积极小，不预加载任何重型库 |

## 2. 设计原则

1. **极速启动**：无启动屏、无广告、无过度动画；首屏直接渲染课表主页面。
2. **极简 UI**：中性色 + 单一主色调点缀；卡片圆角克制、阴影轻、留白充足、文字层级清晰。
3. **本地优先**：零远程依赖、纯静态资源，打开即用。
4. **数据自主**：课程通过手动添加/编辑维护，导出备份为单个 JSON 文件。
5. **隐私本地化**：所有数据只存本机，可随时导出备份。

## 4. 页面结构与交互逻辑

### 4.1 课表页
- **结构**：横向可滚动的 7 列网格（周一~周日），首列为节次时间轴（按开始时间分组标注「上午 / 下午 / 晚上」+ HH:MM 起止时间），表头显示星期与当日日期；本周列高亮。
- **交互**：
  - 点击**空白格** → 打开课程新增弹层（星期、节次已预填）。
  - 点击**课程卡** → 弹窗展示**完整详情**（教师、周次、备注、教室、节次），可一键编辑或删除。
  - 顶栏 `‹ ›` 切换周次，点击中间标签打开周数选择器；「本周」一键回到自动周。
  - 当前时间段所在格子显示「现在」高亮。
- **性能**：一次全量渲染 ≤ 84 个格子 + 课程卡，毫秒级完成。

### 4.2 今日页（默认首页，v1.13 起）
- **结构**：顶部「下一节课」实时倒计时卡片 + 今日课程时间线列表。
- **交互**：应用默认落在今日页；倒计时每秒刷新（上课中显示「距下课」，未上课显示「距上课」，无课显示结束语）；点击课程卡可编辑；点击倒计时卡片跳转课表页本周视图。

### 4.3 倒数日页（原「倒计时」，v1.14 起）
- **结构**：顶部「下一个倒数任务」卡片（最近任务，按 天/时/分 精确倒数，不再重复课程的下一节课）+「倒数日」列表（全部任务）。
- **交互**：右下角 `+` 新增倒数日（标题/目标日期/目标时间（精确到分钟）/备注）；点击条目编辑或删除；**默认按时间排序**，**长按约 0.45s 后拖动可换位**（手动顺序保存后不再自动重排）；剩余天数徽标（今天 / 还有 X 天 / 已过 X 天），**低于「倒数预警值」的条目整卡标红**。

### 4.4 设置页
- **外观**：主题横排色卡一键切换；主色调取色器（自定义后覆盖主题色）；深色模式（跟随系统/浅色/深色）；**时间显示模式**（大学·双节合并 / 中学·每节单独）。
- **学期与周数**：开学日期（自动推导当前周）、总周数、周数模式（自动跟随日期 / 手动锁定）、「设为本周」；节次时间表可增删改、一键恢复默认（**折叠收起，展开后编辑**）。
- **提醒**：上课提醒开关、提前分钟数、浏览器通知授权（网页端说明文案）；**倒数预警值（天）**：剩余天数低于该值的倒数日标红。
- **数据**：导出备份、清空全部数据。

### 4.5 全局交互规范
- 所有触控目标 ≥ 44px；表单弹层内「星期」用七段按钮、「重复周次」用单双周分段 + 自定义周次复选网格。
- 删除等破坏性操作有确认框；所有操作有轻量 Toast 反馈；无花哨动效（仅 0.15s 淡入）。

## 5. 核心流程详解



### 5.1 手动添加/编辑课程
- 字段：课程名称*、教室、教师、星期、开始/结束节次（**默认连续 2 节**）、重复周次（每周 / 单周 / 双周 / 自定义多选）、颜色标签（预设 10 色 + 取色器）。
- 校验：名称必填、结束节次 ≥ 开始节次，错误就地 Toast 提示。

### 5.2 上课提醒
- 开启后每 30 秒检测：当天、当前周内、开始时间落在「现在 ~ 现在+提前分钟」窗口且未提醒过的课程 → 触发浏览器通知 + 应用内 Toast；已提醒记录按天自动清理。
- 网页端通知受浏览器权限限制（见第 9 节）。

### 5.3 备份
- 导出：下载单个 JSON（版本号 + 全部课表/倒数日/设置）。

### 5.4 Excel / CSV 导入课表（v1.24）
- **入口**：设置 → 数据 → 「Excel / CSV」或「粘贴表格」。解析模块 `excel-import.js` **点击时才按需加载**，首屏体积零增加。
- **零第三方依赖**：不引 SheetJS / JSZip；`.xlsx` 用自研 ZIP + XML 解析（含合并单元格铺满），解压优先用浏览器原生 `DecompressionStream('deflate-raw')`，旧 WebView 自动回退到内置纯 JS inflate。
- **两种布局自动识别**（相同结果取数量更多者；都识别不出可手动指定）：
  - **网格表**：表头 周一~周日，行首 `第N节` 或 `08:00-08:45`，格内如 `高等数学 A-101` / `高等数学\n张老师\nB-203\n1-16周`；**合并单元格自动识别为连堂**，同一门课散落多格自动归并。
  - **列表表**：一行一门课，列顺序任意，按表头关键词映射（课程名/星期/节次/教室/教师/周次/备注）。
- **字段归一化**：周次支持 `1-16周`、`1,3,5周`、`单周`、`双周`、`1-8,10-16周`；节次支持 `第1-2节`、`3节`、时间区间（按 `slotTimes` 就近匹配）；颜色按课程名哈希稳定取色。
- **导入预览（必校对方可落库）**：逐条列出 `课程 · 星期 节次 · 教室 · 教师 · 周次`，标出**与现有课表的时间冲突**与**待确认项**（缺教室、周次未识别）；每条可「编辑」（复用课程编辑弹层）或勾选「忽略」。
- **两种落库方式**：**追加导入**（`名称+星期+节次+教室` 完全相同视为重复自动跳过）／**覆盖全部**（二次确认，导入前自动快照，toast 内「撤销」可一键还原）。
- **不支持 `.xls`**（Excel 97-2003 二进制），会提示另存为 `.xlsx` 或 `.csv`。


## 6. 数据模型

```jsonc
{
  "version": 1,
  "meta": {
    "semesterStart": "2025-09-01",   // 开学日期（周一），用于自动计算当前周
    "totalWeeks": 20,                // 学期总周数
    "weekMode": "auto",              // auto=跟随日期 | manual=手动锁定
    "currentWeek": 1,                // 手动模式下的当前周
    "slotTimes": ["08:00-08:45", "08:55-09:40", "…"],  // 节次时间表，可增删改
    "theme": "blue",                 // 内置主题 id
    "accent": "",                    // 自定义主色调（空=跟随主题）
    "dark": "auto",                  // auto | light | dark
    "remind": true,                  // 上课提醒开关
    "remindMinutes": 10,             // 提前提醒分钟数
    "notified": [],
    "timeMode": "pair",          // pair=大学（双节时间合并）| single=中学（每节单独）
    "countdownWarn": 3,          // 倒数预警天数（剩余低于此值标红）
    "countdownManual": false     // 倒数日是否已手动排序
  },
  "courses": [{
    "id": "…",
    "name": "高等数学", "room": "A-101", "teacher": "张老师",
    "weekday": 0,                    // 0=周一 … 6=周日
    "startSlot": 1, "endSlot": 2,    // 节次范围（含）
    "weeks": { "mode": "all", "list": [] },  // all | odd(单周) | even(双周) | custom
    "color": "#3b82f6"
  }],
  "countdowns": [{
    "id": "…", "title": "期中考试", "date": "2025-11-05", "time": "09:00", "note": "高数"  // time 选填，精确到分钟
  }]
}
```

存储键：`minimal-timetable-v1`，任何修改即时写回 localStorage。

## 7. 性能与启动策略（硬性要求落地）

| 要求 | 实现 |
|---|---|
| 冷启动快 | 零依赖首屏；HTML/CSS/JS 均为本地文件，无网络请求即可渲染课表 |
| 减少冗余加载 | 渲染仅操作必要 DOM；零远程依赖、零重库 |
| 无开屏广告/复杂动画 | 无启动屏；唯一动效为 0.15s 视图淡入 |
| 打开立刻见课表 | 默认落在今日页，渲染毫秒级；本地数据同步读取 |
| 省电 | 倒计时每秒刷新仅在「今日/倒计时」页可见时执行 |

## 8. 主题系统

内置 6 套极简主题（靛蓝 / 薄荷 / 紫罗兰 / 日落 / 蔷薇 / 墨灰），每套含浅色与深色两套完整色板（背景/卡片/文字/弱化文字/描边），通过 CSS 变量一键切换；自定义主色调以取色器覆盖主题主色；深色模式支持「跟随系统 / 浅色 / 深色」。

## 9. 适配与已知限制

- **适配**：响应式布局；`viewport-fit=cover` + `safe-area-inset` 适配刘海屏与底部手势导航栏；触控目标 ≥ 44px；桌面宽屏下网格自动拉伸；深色/浅色自动适配。**移动端课表（冻结窗格，无横向滚动）**：顶部星期表头（周一~周日 + 日期）**独立于滚动区渲染**，天然固定吸附视口顶部，彻底规避 sticky 冻结错位 bug；一屏完整展示 7 列，列宽随屏自适应（左侧节次列固定宽度，表头与内容严格对齐）；内容区仅允许上下滚动（`overflow-x:hidden` + `touch-action:pan-y`，横向手势一律无效）；左侧冻结列展示「上午 / 下午 / 晚上 分组 + 起止时间」（v1.13 起不再显示节次号一~十二），按开始时间自动分组标注 **上午 / 下午 / 晚上**；**时间显示模式**：大学模式将相邻两节合并为一条时间（如 `08:00-09:40` 跨两行，无课也合并），中学模式每节单独显示；课程色块为**柔和低饱和配色 + 圆角卡片**（与网格线留出边距），只简短展示**课程名 + 教室**；点击色块弹出详情弹窗（课程名称、教室、教师、周次、校区、备注）；**当日整列高亮**：系统日期当天的一整列（含表头、空白格、课程块蒙层）统一淡主色高亮；连堂课程以虚线内框 + 「连堂」角标区分；横屏小高度自动压紧。
- **限制**：网页端浏览器通知需要 HTTPS 或 localhost 且用户授权；数据仅存本机 localStorage，换设备/清缓存前请先导出备份。

## 10. 运行方式

```bash
# 方式一：直接双击 index.html（推荐，零依赖）
# 方式二：本地静态服务器
python -m http.server 8000   # 或 npx serve .
# 手机使用：将三个文件放入手机，或用任意静态托管上传后浏览器打开
```

> 网页版现已支持 **PWA 离线安装**：通过 http/https 访问后，浏览器菜单选择「添加到主屏幕」，即可像 App 一样全屏启动并离线使用（Service Worker 自动缓存全部资源）。

## 11. 打包为安卓 App（APK）

已完成 Capacitor 封装并本地构建出可安装的 APK：

| 项 | 值 |
|---|---|
| 应用包名 | `com.minimal.timetable` |
| 应用名 | 极简课表 |
| 版本 | `versionCode 31` / `versionName 1.31` |
| 最低系统 | Android 6.0（API 23） |
| 目标系统 | Android 15（API 35） |
| 签名 | debug 签名（个人安装使用；上架应用商店需另配 release 签名） |
| 构建产物 | `课表/android-build/android/app/build/outputs/apk/debug/app-debug.apk` |
| 归档产物 | `课表/极简课表-v1.31.apk`（最新版，含 Excel/CSV/.xls 导入、深色模式等） |

**安装方法**：把 APK 传入手机（微信/QQ/数据线均可），点击安装；若提示「未知来源」，在设置中允许安装未知应用即可。

**离线能力**：全部资源本地打包进 APK，**完全离线可用**，不依赖网络。

**重新构建**（修改网页代码后）：

> ⚠️ **工程路径必须是 ASCII**：安卓工程整体位于中文目录 `课表/` 下，AGP 默认会拒绝并报
> "Your project path contains non-ASCII characters"。已在 `android/gradle.properties` 中显式设置
> `android.overridePathCheck=true` 关闭该校验（本机工具链实测可正常构建）。若把工程移到纯英文路径，
> 该行可以删掉。

```bat
cd 课表\android-build
:: 同步 minimal-timetable 最新资源进安卓工程（若 npx 被 PowerShell 执行策略拦截，改用下面 node 直调）
npx cap sync android
:: node node_modules/@capacitor/cli/bin/capacitor sync android
cd android
:: 本仓库实际工具链路径（Capacitor 7 要求 Java 21，JDK17 会报 "invalid source release: 21"）
set JAVA_HOME=D:\deepseek--harness\tools\jdk21
set ANDROID_HOME=D:\deepseek--harness\tools\android
set ANDROID_USER_HOME=D:\deepseek--harness\tools\android-user-home
set GRADLE_USER_HOME=D:\deepseek--harness\tools\gradle-home
:: ANDROID_USER_HOME 是 debug 签名/analytics 目录（>~/.android），缺了会报 "Failed to apply plugin ... C:\Users\*.android"
gradlew.bat assembleDebug --no-daemon
:: 产物：android/app/build/outputs/apk/debug/app-debug.apk，复制为 课表/极简课表-vX.YY.apk
:: 同步改了网页代码时务必先 cap sync，否则 APK 里还是旧资源
```
